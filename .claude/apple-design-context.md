## Product
- **Name**: Prediciotn
- **Description**: Football statistics and forecast web app that shows every player and team stat and forecasts the chance a player or team reaches a stat line, with the reasons.
- **Category**: Sports / data analysis (information and entertainment)
- **Stage**: Development (backend built and tested; frontend is a scaffold: sign-in, sign-up, verify and Markdown pages work, other screens are placeholders)

## Technology
- **UI Framework**: React 18.3 + React Router 6 (Create React App / react-scripts 5), plain CSS in `frontend/src/styles/*.css`. **No Tailwind, no shadcn/ui.**
- **Backend**: FastAPI + MongoDB
- **Architecture**: Single-page web app with two shells: public site (header + phone bottom tab bar with 4 tabs + "More" sheet) and admin panel
- **Icons**: Inline SVG stroke icons (Lucide-style), 20 px, 1.75 px stroke
- **Charts**: Recharts per `docs/04` (`chart1..chart6` in order, no gradients/3D) _(not yet in package.json)_
- **Apple Technologies**: None

## Design System
- **Base**: Apple HIG redesign (see `docs/redesign/hig/README.md`) on top of the custom design system "calm control room" (`docs/04_design_system.md`, tokens in `docs/design_tokens.json`, generated to `frontend/src/styles/tokens.css`). Brand, colours, font and radius are overridable at runtime from site settings.
- **Principles**: Numbers first (big tabular numerals), one screen one job, show why, colour never carries meaning alone, skeletons not spinners, mobile first.
- **Brand Colors**: One brand colour plus three tier colours (Strong ●●●, Solid ●●○, Watch ●○○), up/down, `chart1..chart6`, layered surfaces `surface1..3`
- **Typography**: System font stack (San Francisco on Apple devices), HIG type ramp; tabular numerals on
- **Dark Mode**: Supported. Dark first; light via `[data-theme="light"]`; default follows `prefers-color-scheme`
- **Dynamic Type**: Web equivalent: rem-based, `clamp()` heading sizes; mobile body 15 px; inputs ≥ 16 px (no iOS zoom)

## Accessibility
- **Target Level**: Enhanced: WCAG 2.2 AA
- **Key Considerations**: Contrast 4.5:1 text / 3:1 large text and graphics; visible 2–3 px brand focus ring with 2 px offset; 44 × 44 px touch targets; respect `prefers-reduced-motion`; no horizontal scroll at 320–390 px; colour backed by labels/dots; `data-testid` on all interactive elements

## Users
- **Primary Persona**: Football fans and analysts who want to understand a match through numbers: fantasy players, writers, podcasters, coaches' assistants, students of the game
- **Key Use Cases**: Look up player/team stats; read a forecast and its reasons; compare lines; follow live matches _(inferred from docs 25–34)_
- **Known Challenges**: Dense data on small screens (tables must become cards ≤ 768 px); strict compliance copy (no betting/odds/tips/picks/stake/value/edge/promotion words; footer disclaimer "Statistical analysis for information and entertainment. Not betting advice."); admin is a separate dense surface
